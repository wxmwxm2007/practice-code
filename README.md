# practice-code
一款 Web 日志安全可视化分析工具：Python + Flask 后端解析 Nginx/Apache combined 访问日志，输出访问趋势、Top IP/URL、状态码与方法分布；12 条规则与阈值检测覆盖 SQL 注入、路径遍历、XSS、命令注入、敏感路径、工具 UA、目录扫描与登录爆破，告警分三级并可导出 CSV；13570 行日志 0.3 秒完成分析，检出 558 条告警。前端为原生 HTML/JS + ECharts 深色仪表盘，7 个图表、告警明细 / 聚合双视图，支持按等级筛选导出。解析用正则按双引号与方括号边界定位，坏行跳过不中断；规则与阈值外置在 rules.json，可自行扩展。代码经 Git 管理，13 次提交，含 28 项单元测试与完整项目报告。
